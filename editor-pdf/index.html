Editor de páginas PDF

Arrastra aquí un PDF o fotos (JPG/PNG) o haz clic para elegir archivos. Las fotos se convierten en páginas (con efecto escáner opcional).
Después: haz clic en las páginas para seleccionarlas, arrástralas para reordenar,
y usa los botones para girar, quitar o añadir hojas de otro PDF.
Todo se procesa en tu ordenador: ningún archivo se sube a internet. Atajos: clic = seleccionar · arrastrar = reordenar · R / L = girar · Supr = quitar
